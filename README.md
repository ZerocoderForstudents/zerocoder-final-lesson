# Финальный проект: от идеи до портфолио

Интерактивная веб-презентация для финального урока курса **Zerocoder** — о том, как создать, разработать и опубликовать проект с помощью Claude Code.

---

## Что это такое

10-слайдовая HTML-презентация, которую преподаватель показывает на последнем занятии курса. Студенты узнают, как превратить идею в рабочий кейс для портфолио за 2 недели.

**Стек:** чистый HTML + CSS + JavaScript, без зависимостей. Открывается в браузере как один файл.

---

## Какую задачу решает

Студенты после прохождения курса часто не знают, с чего начать финальный проект: как выбрать идею, как её описать для Claude Code, как оформить результат. Презентация даёт конкретный пошаговый маршрут — от формулировки задачи до публикации на GitHub и выступления на выпускном.

---

## Для кого

**Пользователь:** студент курса Zerocoder, который изучил Claude Code и готовится делать финальный проект для портфолио.

**Контекст использования:** финальный урок курса, демонстрируется преподавателем на экране. Студент может открыть презентацию самостоятельно и пройти по слайдам в своём темпе.

## Как запустить

```bash
# Клонировать репозиторий
git clone https://github.com/ZerocoderForstudents/zerocoder-final-lesson.git

# Открыть презентацию
cd zerocoder-final-lesson/presentation
# Открыть index.html в любом браузере
```

Или просто скачать ZIP и открыть `presentation/index.html`.

---

## Управление слайдами

- **→ / ←** — следующий / предыдущий слайд
- **Клик по точкам** внизу экрана — переход к слайду
- **Кнопки ← →** по бокам экрана
- **Свайп** на мобильном устройстве
