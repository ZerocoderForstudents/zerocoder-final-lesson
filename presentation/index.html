01 — Зачем

Зачем нужен финальный проект

  • Показывает, что вы доводите идею до результата — не только смотрите уроки
  • Собирает навыки курса: Claude Code, проектирование, разработка, публикация
  • Становится первым или очередным кейсом в портфолио
  • Помогает сформулировать профессиональную ценность
  • Может стать основой для фриланс-услуги или внутренней автоматизации

Ключевая мысль: Финальный проект — ваша демонстрация навыков через реальную задачу. Чем ближе проект к жизни, тем сильнее он выглядит в портфолио.

02 — Идея

Как выбрать проект, если идеи нет

Шаг 1
Найти повторяющуюся задачу
Посты, отчёты, заявки, заметки, описания товаров
Шаг 2
Найти боль или неудобство
Что занимает больше всего времени? Где ошибки?
Шаг 3
Сформулировать идею сервиса
«Было: вручную. Проект: автоматически»
Шаг 4
Ограничить до MVP
Не платформа, а конкретный рабочий инструмент
Шаг 5
Проверить по критериям
Понятный · Полезный · Завершённый · Демонстрируемый · Реальная задача · Выполнимый за 2 недели

Ключевая мысль: Проект рождается не из «что бы придумать?», а из «какую реальную задачу я могу упростить с помощью Claude Code?»

03 — Описание

Как описать проект для Claude Code

  • Название — короткое и понятное
  • Проблема — какую задачу решает проект
  • Пользователь — для кого создаётся
  • Основная функция — что сервис должен делать
  • Формат результата — что видит пользователь на выходе
  • Минимальный функционал — что должно быть в первой версии
  • Технологии — Python, Flask, HTML/CSS и т.д.

Ключевая мысль: Claude Code работает лучше, когда получает не «сделай проект», а описание задачи, пользователя, результата и ограничений.

04 — Разработка

Разработка проекта в Claude Code

  • Создать рабочую папку: product-description-generator
  • Открыть папку в Claude Code
  • Попросить составить план — сначала структура, потом код
  • Создать минимальную рабочую версию (MVP)
  • Запустить локально и проверить основные сценарии
  • Попросить улучшить интерфейс и тексты
  • Попросить подготовить README и инструкцию по запуску

Ключевая мысль: Для портфолио важно не только то, что проект существует, но и то, что его можно показать — интерфейс, сценарий, результат, ссылка.

06 — GitHub

GitHub: профиль, репозиторий и публикация

GitHub — это витрина проекта не только для разработчиков. Здесь лежит код, описание, инструкция и доказательство выполненной работы.

  • Регистрация и оформление профиля
  • Создание репозитория под проект
  • Загрузка файлов: код, README, скриншоты
  • Публикация проекта на GitHub Pages или сервер
  • Ссылка в портфолио и резюме

Практика: Регистрация на GitHub → оформление профиля → публикация проекта → ссылка в портфолио.

07 — Skill

Skill для своего проекта

Создаём инструкцию для Claude Code, которая помогает работать с проектом правильно. Скиллом можно делиться с коллегами и знакомыми.

Создай skill для моего проекта. Он должен помогать Claude Code работать с этим репозиторием: понимать структуру, запускать сервис, вносить изменения, обновлять README, проверять ошибки и готовить проект к публикации.

Ключевая мысль: Skill показывает, что студент умеет не только сделать проект, но и описать правила работы с ним для AI-ассистента.

08 — Выпускной

Как будет проходить выпускной

Онлайн-выпускной в формате демонстрации проектов. 3–5 минут на каждого. Подготовьте презентацию с Claude + демонстрацию проекта вживую.

1
Что я сделал(а) — название и краткое описание
2
Какую проблему решает — почему это важно
3
Как работает — живая демонстрация сценария
4
Результат — ссылка, скриншоты, GitHub
5
Что доработать дальше — 1–2 идеи развития
